# 杭州公交地图认知游戏

一个面向孩子的公交地图认知小游戏，基于腾讯地图 GL JS。打开 `bus-map-game.html` 即可游玩，无需安装依赖或配置密钥。

## 玩法

- 选择杭州真实公交线路（7 路、游 2/Y2 路、1 路），公交会在真实地图上沿线行驶并逐站语音报站。
- 到站后停靠 10 秒并弹出该站附近的实景图片，同时显示站点小知识。
- 支持中英文报站切换、车速调节、卫星地图切换、镜头跟随。
- 可新建自定义线路：搜索地点或直接点地图添加站点；支持上传公交车图片、车身颜色和车型设置，设置保存在浏览器本地。

## 运行

直接用浏览器打开 `bus-map-game.html`，或在仓库目录启动静态文件服务器（例如 `python -m http.server`）后访问该文件。页面需要联网加载腾讯地图底图和路线规划服务。

## 文件说明

- `bus-map-game.html`：完整单文件游戏，公交车与站点实景图片均已内嵌。
- `generated-images/`：生成过程中用到的图片素材源文件，不影响运行。
